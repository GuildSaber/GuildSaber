# GuildSaber.Website

Regarding the website, we've opted for a React + TypeScript with Vite.
And to accelerate and make it more robust, we are using an auto-generated API client using the OpenAPI specification
provided by the API. At build and initial run dev time, the client is generated and made available for the website to
use.

Things are still in early stage of developments. Just know that the website is statically served by the API directly.
